# Security Policy

## Supported Versions
| Version | Supported |
|---------|-----------|
| 0.1.x   | ✅ Preview |

## Reporting a Vulnerability
Please **do not** open a public issue for sensitive reports.

- Use GitHub **Security → Advisories → New draft advisory** on the repository, or
- Email the maintainers listed in `CODEOWNERS` / contact on the Support page.

Include steps, impact, and suggested fix if known. We aim to respond within 72h.

## What to expect
We will confirm, develop a fix, and coordinate disclosure. Thank you for helping keep DOTX safe.
